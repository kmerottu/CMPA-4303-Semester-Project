# Reflection
## Decisions
I wanted to make a clean and professional website that showcased my photography skills while also showing how much i have learned about coding a website. I believe one of the most important decsisions i made when making this website is updating the way photographs are displayed. This decision has made the entire website more functionally and asthetically pleasing.
## What Worked
The basic website coding worked well and was straightforward. I am most satisfied with how the gallery functions and that each photo can be filtered out by genre.
## What Would You Do Differently
If i had to do it all over again i would look to integrate a storage solution such as smugmug for the photos. By using this strategy it would be much easier to store, catalog, and have a much more streamlined workflow.
## What you learned
I have learned that building for the web is not as scary as it seems, as long as you use great tools it can be a pretty straight forward process. Buidling this photgraphy website taught me a lot about web development and the importance of designing with the use in mid. During this project, i learned more how to be a probem solver, at times things did not work such as the button styling did not work, which was frustrating. however working through those problems helped me become more patient and persistent. I realized debugging and testing are importatn parts of coding, and mistakes are opportunities to learn rather than failures.
